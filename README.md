# HyperMedia_Lite

一个基于 UWP（C# + XAML）的本地音频 / 视频 / 图片查看器，采用 Groove 风格的三栏式布局与 Fluent 设计令牌。

## 运行方式

1. 使用 Visual Studio 2022 打开 `HyperMedia_Lite.sln`（需安装「通用 Windows 平台开发」工作负载与 Windows 11 SDK 10.0.22621）。
2. 在开发者模式下，将应用部署到本地计算机（Debug | x64 或 x86）。
3. 首次启动会在设置中申请音乐 / 视频 / 图片库权限；也可直接点击右上角「添加媒体」选择任意位置的文件（访问权限会保存在应用的 FutureAccessList 中，可在「设置」里清除）。

> 兼容性说明：`Package.appxmanifest` 声明最低版本 10.0.15063，工程 `HyperMedia_Lite.csproj`
> 的编译期 `TargetPlatformMinVersion` 为 10.0.16299.0（规避旧版 .NET Native 编译器问题），
> 并保留 `Windows.Mobile` TDF。现代播放 API 通过 `UwpCompat` 守卫，旧系统走兼容后端。
> 详见 `docs/兼容性说明.md`。

## 已实现功能

- **界面布局**：Groove 风格的 72px 窄图标栏 + 自绘 32px 标题栏 + 蓝色底部常驻播放条；点击汉堡按钮展开带文字标签和搜索框的导航面板。导航、页头、列表与播放条按窗口宽度分档自适应。
- **主页（默认启动页）**：最近播放 / 常听（按播放次数）/ 收藏 / 最近添加四个分区；卡片等宽、真实 `Margin` 间距，宽窗两列、窄窗一列，内容居左。启动后不再跳到专辑页。
- **导航视图**：音乐（专辑 / 歌手 / 歌曲，均由真实元数据分组）、最近添加、统计、播放队列、视频、图片、收藏，每项显示真实数量。
- **真实媒体库**：递归扫描系统音乐 / 视频 / 图片库及其所有子文件夹；支持多选文件与「导入文件夹」（含子文件夹），访问权限持久化并在下次启动恢复；去重后读取系统元数据与缩略图。媒体库、播放队列、播放列表均有按场景专业化的多选操作条；支持拖拽导入与分享。
- **播放核心**：单例 `MediaPlayer` + 播放队列；播放 / 暂停、上一首 / 下一首、进度 / 音量 / 倍速；播放顺序可依次切换「顺序 / 随机 / 列表循环 / 单曲循环 / 只播放本曲」并自动记忆；队列面板支持跳播 / 上移 / 下移 / 移除 / 清空；后台音频、SMTC 媒体中心同步、封面取色、睡眠定时。
- **图片灯箱**：`Controls/ImageViewer` 支持捏合 / 滚轮 / 双击缩放、拖动平移、适应窗口、旋转 / 翻转、换图过渡动画、缩略图占位、加载环与缩放百分比提示。鼠标滚轮行为可在**设置页**选择「缩放图片 / 平移画面 / 切换图片」；放大后可用鼠标左键拖动平移，触摸左右滑动可在适应窗口状态下翻页。底部胶片条会凸显并居中当前图片，支持滚轮与鼠标 / 手指拖动。键盘：←/→ 切图，0/F 适应，+/- 缩放，R 旋转，I 信息，空格幻灯片，Esc 退出。
- **图片服务**：`ImageLoaderService`（LRU 缩略图缓存、4K 降采样、GIF 保留动画）与 `ImageInfoService`（EXIF 读取）；支持设为壁纸、打印、磁贴轮播与幻灯片。
- **图片编辑器 `EditPage`**：灯箱中点击「编辑」进入；框选裁剪、旋转 / 翻转、亮度 / 对比度 / 饱和度、色温 / 色调、黑白 / 反色 / 怀旧 / 暖色 / 冷色 / 胶片滤镜（实时预览）、模糊 / 锐化 / 暗角、水印（字体 / 颜色 / 字号）、相框（颜色 / 位置）、撤销 / 重做与另存为 JPEG/PNG。宽窗左右分栏、窄窗上下分栏，工具面板可收起，次要操作进溢出菜单。
- **歌词（移植自 HyperMedia）**：MP4/M4A 内嵌歌词、同名 `.lrc/.krc/.qrc/.txt` 文件（含 KRC 解密与编码探测）、网易云 / QQ 在线搜索与候选选择、本地缓存；正在播放页支持歌词高亮、逐字卡拉OK着色、「换词」与桌面歌词悬浮窗；字幕时间偏移可调。
- **音乐元数据与统计**：`MetadataPage` 可编辑标题 / 艺人 / 专辑 / 专辑艺人 / 副标题 / 曲目号 / 年份 / 评分 / 流派 / 作曲并写回文件；`PlayStatsService` 本地持久化播放次数与最后播放时间，**自动统计默认关闭**，需在设置页手动开启。
- **视频字幕（自绘，无 VLC）**：自动加载同名 `.srt/.vtt/.ass/.ssa`，也可在播放页手动加载；支持 ASS 样式 / 覆盖标签与外挂字幕自绘；画中画、画面模式（适应 / 填充 / 拉伸 / 原始）。
- **收藏与排序**：收藏状态写入本地设置；支持按标题 / 最近添加 / 时长排序。
- **诊断日志**：`LocalState\debug.log`；启动、歌词、字幕、磁贴与 `[WHEEL]` 滚轮输入日志可导出 / 清理（Debug 构建默认开启，Release 需在设置页开启）。
- **空状态与错误提示**：无媒体时给出可操作的引导，权限被拒绝或文件失效时静默跳过并记录状态。

## 目录结构

```
Controls/     ImageViewer（图片灯箱控件：缩放/平移/手势/滚轮）
Models/       MediaItem（真实媒体文件）、NavItem（导航项）
ViewModels/   MainViewModel（导航、主页、统计、播放状态转发）
Services/     LibraryService、PlaybackService、PlayStatsService、ImageEditService、
              PhotoViewerSettings、TileService 等
Helpers/      BindableBase、RelayCommand、转换器、DebugLog
docs/         界面设计规范、设计报告、ROADMAP、未来规划、兼容性说明、
              Milestone_2.4_to_3.0_Report（中英双语改进报告）
```

## 响应式布局

主界面与各页面使用 `AdaptiveTrigger + VisualState.Setters` 做四档响应：
- **极窄（<420 epx）**：只保留核心操作——曲目文字、播放顺序模式、音量和翻转按钮全部折叠进各自的「更多」菜单；封面缩到 40px；播放条为「上排控制 + 下排整行进度条」两行结构，高度 92px，控件不会被裁切。
- **窄（420–640 epx）**：导航栏 56px；标题与内边距缩小；排序下拉框、刷新/文件夹按钮与「无序播放」文字折叠进工具条「更多」菜单；封面 48px、曲目文字限宽 120px；音量条缩到 52px，歌词/更多/展开进播放条「更多」菜单；灯箱翻转按钮进「更多」菜单。窗口变宽时这些按钮自动恢复，菜单入口自动隐藏。
- **中（641–1023 epx）**：保留主要控件，收紧播放条与网格间距，隐藏歌词/更多按钮。
- **宽（≥1024 epx）**：完整布局。

灯箱信息栏宽度还会按窗口宽度动态限制（`min(300, max(180, 窗口宽-260))`）。编辑页以 700px 为阈值：宽窗左右分栏（260px 工具面板 + 预览），窄窗上下分栏（预览在上、可滚动面板在下），面板可通过工具栏按钮收起；主页卡片宽窗两列、窄窗一列。

## 兼容性

部署最低版本为 **Windows 10 15063**（`Package.appxmanifest` 中的 TDF），编译期 `TargetPlatformMinVersion` 为 **10.0.16299.0**（规避旧版 .NET Native 编译器问题），并保留 `Windows.Mobile` TDF。运行时通过 `UwpCompat` / `ApiInformation` 守卫按 API 合同降级：现代路径使用 `MediaPlayerElement` / `MediaPlaybackSession` / SMTC / 内嵌字幕轨，旧系统使用兼容后端与自绘字幕。详见 `docs/兼容性说明.md`。

设计令牌（颜色、字体、尺寸）集中在 `App.xaml`，完整设计说明见 `docs/界面设计规范.md`、`docs/设计报告.md`；后续方向见 `docs/ROADMAP.md` 与 `docs/未来规划.md`；从 Milestone 2.4 到 3.0 的改进总览见 `docs/Milestone_2.4_to_3.0_Report.md`（中英双语）。
