# HyperMedia_Lite

一个基于 UWP（C# + XAML）的本地音频 / 视频 / 图片查看器，采用 Groove 风格的三栏式布局与 Fluent 设计令牌。

## 运行方式

1. 使用 Visual Studio 2022 打开 `HyperMedia_Lite.sln`（需安装「通用 Windows 平台开发」工作负载与 Windows 11 SDK 10.0.22621）。
2. 在开发者模式下，将应用部署到本地计算机（Debug | x64 或 x86）。
3. 首次启动会在设置中申请音乐 / 视频 / 图片库权限；也可直接点击右上角「添加媒体」选择任意位置的文件（访问权限会保存在应用的 FutureAccessList 中，可在「设置」里清除）。

> 媒体播放使用 `MediaPlayerElement` / `MediaPlaybackSession`（Windows 10 1607 / 14393 起提供），
> 因此完整功能需要 Windows 10 1607 或更高版本；项目保留 10240 的最低版本声明以兼容原有工程配置。

## 已实现功能

- **界面布局**：Groove 风格的 92px 窄图标栏 + 「我的音乐」标题 / 歌曲-歌手-专辑选项卡 / 无序播放与排序工具条 + 专辑封面网格 + 蓝色底部播放条；点击汉堡按钮展开带文字标签和搜索框的导航面板。
- **导航视图**：音乐（专辑 / 歌手 / 歌曲，均由真实元数据分组）、最近添加、统计、播放队列、视频、图片、收藏，每项显示真实数量。
- **真实媒体库**：递归扫描系统音乐 / 视频 / 图片库及其所有子文件夹；支持多选文件和「导入文件夹」（自动包含子文件夹），访问权限持久化并在下次启动恢复；去重后读取系统元数据（标题、艺人、专辑、分辨率、时长）与缩略图。
- **播放核心**：单例 `MediaPlayer` + 播放队列；播放 / 暂停、上一首 / 下一首、进度跳转、音量控制；播放顺序按钮可依次切换「顺序 / 随机 / 列表循环 / 单曲循环 / 只播放本曲」并自动记忆；点击迷你播放器封面或展开按钮进入全屏「正在播放」页，视频在浮层中渲染。
- **图片灯箱（忠实移植 HyperViewer）**：`Controls/ImageViewer` 支持渲染级缩放（滚轮/Ctrl+滚轮/双击/捏合）、拖动平移、适应窗口、旋转/翻转、换图过渡动画（Fade/Zoom/Pan/Flicker）、缩略图占位与加载环、缩放百分比提示及 10240 自适应；灯箱提供信息侧栏（尺寸/大小/EXIF/GPS 等）、底部胶片条、幻灯片播放、失败重试与键盘操作（←/→ 切图，0 适应，+/- 缩放，R 旋转，F 适应，I 信息，空格幻灯片，Esc 退出）。
- **图片服务**：`ImageLoaderService`（LRU 缩略图缓存、4K 降采样、GIF 保留动画）与 `ImageInfoService`（EXIF 读取）。
- **图片编辑器 `EditPage`**：灯箱中点击「编辑」进入；支持拖拽框选裁剪、旋转/翻转、亮度/对比度/饱和度、色温/色调、黑白/反色/怀旧/暖色/冷色/胶片滤镜、模糊/锐化/暗角、撤销/重做与另存为 JPEG/PNG。核心算法移植自 HyperViewer 的 `ImageEditService`。
- **歌词（移植自 HyperMedia）**：MP4/M4A 内嵌歌词、同名 `.lrc/.krc/.qrc/.txt` 文件（含 KRC 解密与编码探测）、网易云/QQ 在线搜索与候选选择、本地缓存；正在播放页支持歌词高亮、逐字卡拉OK着色、「换词」与桌面歌词悬浮窗。
- **视频字幕（自绘，无 VLC）**：自动加载同名 `.srt/.vtt/.ass/.ssa`，也可在播放页手动加载；支持 ASS 样式/覆盖标签，全部用 10240 可用的 XAML 绘制。
- **收藏与排序**：收藏状态写入本地设置；支持按标题 / 最近添加 / 时长排序。
- **空状态与错误提示**：无媒体时给出可操作的引导，权限被拒绝或文件失效时静默跳过并记录状态。

## 目录结构

```
Models/       MediaItem（真实媒体文件）、NavItem（导航项）
ViewModels/   MainViewModel（导航、列表、收藏、播放状态转发）
Services/     LibraryService（扫描/选择器）、PlaybackService（播放核心）
Helpers/      BindableBase、RelayCommand、转换器
docs/         界面设计规范、设计报告
```

## 响应式布局

主界面与各页面使用 `AdaptiveTrigger + VisualState.Setters` 做四档响应：
- **极窄（<420 epx）**：只保留核心操作——曲目文字、播放顺序模式、音量和翻转按钮全部折叠进各自的「更多」菜单；封面缩到 40px；播放条为「上排控制 + 下排整行进度条」两行结构，高度 92px，控件不会被裁切。
- **窄（420–640 epx）**：导航栏 56px；标题与内边距缩小；排序下拉框、刷新/文件夹按钮与「无序播放」文字折叠进工具条「更多」菜单；封面 48px、曲目文字限宽 120px；音量条缩到 52px，歌词/更多/展开进播放条「更多」菜单；灯箱翻转按钮进「更多」菜单。窗口变宽时这些按钮自动恢复，菜单入口自动隐藏。
- **中（641–1023 epx）**：保留主要控件，收紧播放条与网格间距，隐藏歌词/更多按钮。
- **宽（≥1024 epx）**：完整布局。

灯箱信息栏宽度还会按窗口宽度动态限制（`min(300, max(180, 窗口宽-260))`），编辑页工具面板在窄窗口从 260px 收至 200px。

## 兼容性

项目最低版本为 10.0.10240。已做两手准备：运行时按 API 合同动态降级（10240 上音频播放正常、视频交系统播放器），或按需把最低版本提升到 14393 并移除兼容分支。详见 `docs/兼容性说明.md`。

设计令牌（颜色、字体、尺寸）集中在 `App.xaml`，完整设计说明见 `docs/界面设计规范.md` 与 `docs/设计报告.md`。
