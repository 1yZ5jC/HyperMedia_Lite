# HyperMedia_Lite 界面设计规范

> 版本：v1.0（可运行版） ｜ 日期：2026-11-22
> 适用范围：本地音频 / 视频 / 图片查看器（UWP + C# + XAML）
> 依据：Windows Groove 音乐设计语言 + 微软 Fluent Design 指南 + PyQt「Groove 复刻」参考图（cnblogs zhiyiYo/p/16183978）
> 对应实现：`MainPage.xaml` / `MainPage.xaml.cs` / `App.xaml` / `ViewModels/MainViewModel.cs` / `Services/`
>
> **实现更新说明**：本文档第 3 节保留了最初首页初稿的视觉稿描述供设计评审参考；
> 其中「92 px 图标导航条 / 歌曲-歌手-专辑选项卡 / 示例专辑与示例曲目」已由可运行版本取代：
> 导航改为基于 `SplitView` 的汉堡菜单（音乐 / 视频 / 图片 / 收藏 / 播放队列 + 搜索），
> 内容来自真实媒体库，播放条接入 `MediaPlayer`。当前实际行为以第 4、5 节为准。

---

## 1. 设计目标

在 Windows 原生质感的前提下，复刻 Groove 的三个核心体验：

1. **内容优先**：封面 / 缩略图是主角，界面 chrome 尽量退后。
2. **随时可控**：一个跨页面常驻的播放层（底部播放条）。
3. **安静一致**：中性底色 + 单一强调色，Segoe 排版，克制动效。

整体结构（三栏式）：

```
┌────────┬───────────────────────────────────────────────┐
│        │  我的音乐                                       │
│  左侧  │  歌曲   歌手   专辑                             │
│  导航  │  [⇄ 无序播放所有]  排序依据: 添加时间 ▾          │
│ (92)   │                                               │
│        │   ▢ ▢ ▢ ▢ ▲   （媒体卡片网格 / 空状态）        │
│        │                                               │
├────────┴───────────────────────────────────────────────┤
│ ▶ 曲目信息   ⇄ ⏮ ▶ ⏭ 🔂   进度 ────●────    音量 词 ⋯ │
└──────────────────────────────────────────────────────────┘
```

## 2. 设计令牌（Design Tokens）

定义位置：`App.xaml` → `<Application.Resources>`（全局，供页面与转换器共用）。

### 2.1 颜色

| 资源键 | 值 | 用途 |
| --- | --- | --- |
| `AccentBrush` | `#FF00A3B4` | 全局强调色：选中态、下划线、主按钮、进度、播放条背景 |
| `AccentPressedBrush` | `#FF008C9A` | 强调色按下态 |
| `SurfaceBrush` | `#FFFFFFFF` | 右侧内容区表面 |
| `NavBackgroundBrush` | `#FFF7F7F7` | 左侧导航浅灰表面 |
| `NavForegroundBrush` | `#FF6B6B6B` | 导航未选中图标 |
| `PageBackgroundBrush` | `#FFF1F1F1` | 窗口/页面背景 |
| `TextPrimaryBrush` | `#FF1A1A1A` | 主文字 |
| `TextSecondaryBrush` | `#FF767676` | 次文字 |

局部透明度（写在 XAML 中，暂未提为令牌）：

| 值 | 用途 |
| --- | --- |
| `#FFEDEDED` | 汉堡按钮浅灰底 |
| `#CCFFFFFF` | 底部封面底（白 80%） |
| `#DDFFFFFF` | 底部艺人文本（白 87%） |
| `#66FFFFFF` | 播放条 Slider 轨道（白 40%） |
| `#59FFFFFF` | 卡片封面上的大字（白 35%） |

原则：中性色做底，强调色只用于「选中 / 进度 / 主操作」，保持低饱和、高可读（对比度、色盲友好见 Fluent Color 指南）。

## 3. 组件设计元素

### 3.1 左侧导航

- **容器**：92 px 宽、`NavBackgroundBrush` 浅灰，与内容区形成明度差。
- **顶部**：两个 48×48 按钮横排——返回（强调色实底、白色图标）、汉堡菜单（浅灰底 `#EDEDED`、深色图标）。
- **中部**：`ListView`（`SelectionMode=None` + `IsItemClickEnabled=True`）承载导航项，逐项点击切换选中。
- **单项模板**：92×56 网格；左侧 3×30 强调色竖条（选中可见）+ 居中的 22 px 图标。
  - 未选中：`NavForegroundBrush`
  - 选中：`AccentBrush` 图标 + 显示竖条
- **底部**：设置按钮，贴底贴左。
- **无障碍**：每项设置 `AutomationProperties.Name`。

### 3.2 内容区头部

- **标题**：「我的音乐」，30 px SemiBold。
- **选项卡**：`歌曲 / 歌手 / 专辑` 三个纯文本按钮，水平排列，间距 28。
  - 未选中：次文字色，无下划线
  - 选中：主文字色 + 强调色 2 px 下划线
  - 由代码隐藏 `SetTab()` 维护外观（当前版本未用 Pivot，以便精确控制颜色与最低版本兼容）。
- **工具条**（位于选项卡下方）：
  - 「⇄ 无序播放所有 (210)」：shuffle 图标 + 计数文本
  - 「排序依据: 添加时间 ▾」：值用强调色，带展开箭头

### 3.3 内容主体

- **专辑页（默认）**：`GridView`，卡片流。
  - 卡片：180 宽、方形封面（纯色占位 + 首字母大字水印）+ 标题/副标题两行文本。
  - 文本单行省略（`TextWrapping=NoWrap` + `TextTrimming=CharacterEllipsis`）。
  - 选择模式 Single。
- **歌曲 / 歌手页**：当前展示空状态——
  - 文案「这里没有可显示的内容。请尝试其他筛选器。」
  - 次文字色、左上定位，模拟首次使用的空库状态。

> 占位封面说明：当前用纯色 + 首字母代替真实专辑封面，用于界面设计评审；接入媒体库后替换为 `StorageItemThumbnail`。

### 3.4 底部常驻播放条

- **容器**：全宽、高 96、`AccentBrush` 背景、白字。
- **三列布局**：
  1. **左**：56×56 封面占位（半透明白底 + 曲名首字）+ 曲名/艺人两行。
  2. **中**：传输控制行（随机 / 上一首 / 播放 / 下一首 / 循环）+ 进度行（当前时间 `0:50`、Slider、总时长 `4:59`），整体居中。
  3. **右**：音量图标 + 120 宽 Slider + 「词」（歌词）+ 「⋯」（更多）。
- **播放键**：48×48 按钮内含 40 直径 1.5 px 白色描边圆 + 16 px 播放三角。
- 交互控件统一走 `PlaybackIconButtonStyle`（透明底、白字、40×40）。

## 4. 交互与状态（可运行版）

| 交互 | 当前行为 |
| --- | --- |
| 点击汉堡按钮 | 展开 / 收起 `SplitView` 左侧导航面板（Overlay 模式，含搜索框与设置入口） |
| 点击导航项 | `MainViewModel.Select(target)` 切换音乐 / 视频 / 图片 / 收藏 / 播放队列视图，并自动收起面板 |
| 在搜索框输入 | 按标题 / 副标题即时过滤当前视图 |
| 点击「添加媒体」 | 打开文件选择器多选；通过 `FutureAccessList` 记住访问权限，下次启动自动恢复 |
| 点击「刷新媒体」 | 重新扫描系统音乐 / 视频 / 图片库并与已保存文件去重合并 |
| 点击媒体卡片 | 图片进入灯箱（可前后切换）；音频 / 视频填充播放队列并开始播放，展开「正在播放」浮层 |
| 点击卡片爱心 | 收藏 / 取消收藏，写入本地设置，导航项数量同步更新 |
| 播放条 / 浮层按钮 | 播放 / 暂停、上一首、下一首、随机、循环、进度跳转、音量，全部作用于同一个 `MediaPlayer` |
| 设置 | 重新扫描媒体、清除已保存的文件访问权限 |
| 主题 | 页面 `RequestedTheme="Light"`；跟随系统主题与媒体取色留待后续 |

## 5. 实现结构与文件映射（可运行版）

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 视图 | `MainPage.xaml` / `.xaml.cs` | `SplitView` 汉堡导航、媒体网格、迷你播放条、正在播放浮层、图片灯箱 |
| 视图模型 | `ViewModels/MainViewModel.cs` | 导航、搜索、列表、收藏、排序、播放状态转发 |
| 模型 | `Models/MediaItem.cs` / `NavItem.cs` | 真实媒体文件（元数据 / 缩略图 / 收藏）、导航项 |
| 服务 | `Services/LibraryService.cs` | 媒体库扫描、文件选择器、访问权限持久化 |
| 服务 | `Services/PlaybackService.cs` | 单例 `MediaPlayer`、播放队列与传输控制 |
| 基础 | `Helpers/BindableBase.cs` / `RelayCommand.cs` | `INotifyPropertyChanged`、`ICommand` |
| 基础 | `Helpers/Converters.cs` | `BoolToVisibility`、`BoolToAccentBrush`、`BoolToOpacity`、`TextToVisibility` |
| 资源 | `App.xaml` / `Package.appxmanifest` | 全局画刷令牌、媒体库能力声明 |

数据绑定以 `{Binding}` 为主，卡片与导航模板内使用 `x:Bind` + `x:DataType`（编译绑定，性能更优）。

## 6. 兼容性约束（最低版本 10.0.10240.0）

为不提升最低版本采用的变通方案：

| 现代写法（≥16299） | 本项目替代 | 原因 |
| --- | --- | --- |
| `StackPanel.Spacing` | 子元素 `Margin` | Spacing 为 16299+ |
| `Border.CornerRadius` | 直角 | CornerRadius 为 16299+ |
| `TextBlock.MaxLines` | `TextWrapping="NoWrap"` | MaxLines 为 16299+ |
| `Binding.StringFormat`（UWP 不支持） | VM 提供现成字符串（如 `PlayAllText`） | UWP Binding 无此属性 |
| Acrylic / Mica 材质 | 纯色表面 | 需 16299+ / Win11 |
| WinUI 2 `NavigationView`/`Pivot` | 原生 `ListView` + 自定义文本选项卡 | 控件或颜色不可控、依赖新包 |

> 后续若需要使用 Fluent 材质与现代控件，需要重新评估最低版本策略；在此之前保持上述兼容写法。

## 7. 待确认 / 后续阶段

1. 导航与播放条图标字形是否正确（尤其音乐/最近/统计/列表）。
2. 强调色 `#00A3B4` 是否保留，或改为 Groove 式紫粉 / 封面取色。
3. 默认进入「专辑」还是「歌曲」。
4. 是否需要深色主题。
5. 是否要做无边框圆角窗口。
6. 接入真实媒体库：`LibraryScanService`、`MetadataService`（`MusicProperties`/`VideoProperties`/`ImageProperties`）、`AccentColorService`（封面取色）。
7. 视频与图片查看器的对应页面（延续同一套令牌与布局规则）。
