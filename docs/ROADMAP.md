## P1：核心体验补齐（按推荐顺序）

- [x] **P1-1 系统媒体控制 SMTC**：同步曲名/封面/播放状态到系统媒体中心，支持媒体键控制
- [x] **P1-2 封面取色 AccentColorService**：从专辑封面/视频帧提取主色驱动沉浸页，带系统色降级
- [x] **P1-3 播放列表 / 收藏管理**：播放列表增删改，本地持久化
- [x] **P1-3b 在线歌词选择面板**：来源切换 / 自定义搜索 / 完整预览 / 本地歌词文件 / 恢复默认歌词；强调色来源与明暗主题分离
- [x] **P1-3c 本地歌词 / 字幕自动匹配**：播放时自动查找同目录同名 `.lrc/.krc/.qrc`（及 `Lyrics` 子目录），视频查同名 `.srt/.ass`；命中直接用，未命中再走在线；用户显式选词优先，并可在面板「恢复默认歌词」清除选择回到内嵌 / 本地
- [x] **P1-3d 图片打印**：灯箱工具栏「打印当前图片」，走 UWP `PrintManager` + `PrintDocument`，按纸张可打印区域居中缩放
- [x] **P1-3e 播放中队列管理**：播放页右侧滑出队列面板，支持跳播 / 上移 / 下移 / 移除 / 清空，无需退出播放页
- [x] **P1-3f 动态磁贴**：正在播放（封面 + 歌名 + 状态，随切歌/播放状态更新）；灯箱按钮把照片推送到磁贴通知队列自动轮播
- [ ] **P1-4 全局搜索页**：暂缓——现有面板内搜索已能满足需要，已回退独立搜索页
- [x] **P1-5 视频画中画 CompactOverlay**：`ApplicationViewMode.CompactOverlay`（360×240），再点一次退出；14393+ 守卫
